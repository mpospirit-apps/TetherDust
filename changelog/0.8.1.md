# 0.8.1 — 2026-08-29

## Upgrade notes for admins
- No migrations and no new environment variables. Rebuild the frontend image:
  `docker compose build frontend && docker compose up -d frontend`.

## Fixed
- Selecting a building in the tether city now dims everything unrelated to it:
  the tethers that do not touch the selection drop to 8% opacity and the other
  buildings to 28%, so the selection's own connections are what is left lit.
  The rules were there but never applied — the entrance fade's settled state
  (`.city.anim.ready .bld, .city.anim.ready .arc-g { opacity: 1 }`) tied with
  them on specificity and won on source order, holding everything at full
  opacity. The entrance now only names the pre-`ready` state and leaves the
  settled one to the rules that dim it, and it sits above them in the file so
  the cascade reads base → entrance → focus. The search dimming, which already
  worked because it happened to be written below the entrance block, is
  unaffected.
