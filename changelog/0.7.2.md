# 0.7.2 — 2026-07-28

## Upgrade notes for admins
- Rebuild the `frontend` container to pick up the Agent form changes below, and
  the `backend`, `codex`/`codex-api`, and `claude`/`claude-api` containers to
  pick up the refreshed default system prompt. Existing agents that already
  have a saved (non-blank) system prompt keep their own text — only the seeded
  default and blank-prompt agents pick up the new wording.

## Changed
- The **Add Agent** "How it works" overview now has a dedicated section per
  integration method (Codex subscription, Codex API key, Claude Code OAuth,
  Claude Code API key, Direct API) and each CLI-backed method ends with an
  explicit "MCP tools only" step: the CLI's own built-in tools (Codex's shell
  tool, Claude Code's Bash/file-edit tools) are disabled or never granted, so
  the model can only call the MCP tools your roles allow — the restriction
  introduced in 0.7.0.
- The Edit Agent form now shares the same numbered steps-wizard layout as Add
  Agent (Identity / Configuration / System Prompt), instead of its own
  unlabeled two-card layout. Field grouping is unchanged; only the "leave
  blank to keep existing" credential hints (API key, OAuth token) are
  edit-specific.
- The System Prompt step is now a read-only rendered preview (matching the
  Generate Documentation "Prompt" step) instead of an editable textarea. It
  still shows the effective instructions — the agent's saved prompt, or the
  container default (AGENTS.md/CLAUDE.md) when unset — but can no longer be
  edited from the admin UI.
- Rewrote the default agent system prompt (`containers/codex/AGENTS.md` and
  `containers/claude/CLAUDE.md`) to accurately describe the current app: the
  five supported database engines (PostgreSQL, MySQL, MariaDB, SQL Server,
  SQLite, ClickHouse), semantic doc/code search, GitHub/GitLab/local codebases,
  reports, dashboards/charts (theme-palette color policy), and tethers. It now
  frames tool availability as decided per request by role, permissions, and
  surface, so the agent only uses the tools actually present. Read-only data
  access, no-shell/no-filesystem, no-internals, no-self-disclosure, the
  `Sources:` response format, and brief out-of-scope decline are preserved.
